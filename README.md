# AnswerEight

Eight-bar second-verse desk for bedroom producers and AI-music finishers.

Suno and loop beds reprint verse one as verse two, then turn the chorus up. Session players rewrite the second verse: thinner kit, a walking upright, a nylon reply, violin in the dry room. Chorus two then has something to come back to.

Live samples only — FluidR3 acoustic piano, upright bass, nylon guitar, violin, trumpet, and an acoustic kit, pinned to PreEight commit `d58301e4a494555f411a2afbc448b724136eee76`. No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the rest of the line

| LiftTwo / ModEight / AfterHook / EndEight / LastHook | Other cuts |

Not a bridge desk (BridgeFour / BridgeEight already exist). Not a chorus desk.

## Run

Open `index.html` or deploy the folder as a static site on Vercel.

Tap to start audio. Set BPM (60–180), key, and a 4-chord progression. Those persist in localStorage and drive playback and export.

Export is 48 kHz, 24-bit stereo WAV, first downbeat at sample 0, ring-out folded onto the start so the loop is seamless. A separate with-tail WAV is labeled. Matching MIDI, one track per chair, tempo and time signature set.
